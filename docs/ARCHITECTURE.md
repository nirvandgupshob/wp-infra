# Архитектура


Трафик приходит через Route53, TLS терминируется на балансировщике, до контейнеров он идёт по обычному HTTP на порт 8080 внутри VPC. Больше до контейнеров не дотянуться: их security group принимает только группу балансировщика. Та же цепочка защищает базу и файловую систему, они принимают только группу задач.

## Окружения

| | staging | production |
|---|---|---|
| VPC | `10.10.0.0/16` | `10.20.0.0/16` |
| NAT | один | по одному на зону |
| Задачи | 2, масштаб до 4 | 2, масштаб до 6 |
| Инстансы Aurora | один | writer и reader в разных зонах |
| Мощность Aurora | 0–2 ACU, засыпает при простое | 0.5–8 ACU |
| Хранение логов | 7 дней | 90 дней |

## Деплой

Задача по тегу ничего не пересобирает. Она находит дайджест, собранный для этого коммита, проверяет его наличие в ECR, вешает тег релиза, снимает снапшот базы production и разворачивает тот же дайджест, который крутился в staging. 

## Хранилище

Ядро WordPress и весь код запечены в образ. На EFS вынесен только `wp-content/uploads`, смонтированный через access point, который навязывает uid/gid 33 и делает корнем `/uploads`. Загрузки обязаны быть общими: файл, записанный одной задачей, должен читаться на следующем запросе, а тот может попасть на любую.

Всё остальное состояние держит база. Поэтому изменения схемы и контента едут через миграции и бэкапы, а не через образ.

## Наблюдаемость

| Сигнал | Куда |
|---|---|
| stdout/stderr контейнеров | CloudWatch Logs, группа на окружение |
| Ошибки и медленные запросы Aurora | CloudWatch Logs |
| Flow logs VPC | CloudWatch Logs |
| Метрики задач и кластера | Container Insights |
| Запросы, коды ответов, задержка | метрики ALB |
| Внешняя доступность | Route53 health check, метрики только в `us-east-1` |


Внешняя проверка Route53 опрашивает `/healthz.php` каждые 30 секунд из нескольких регионов AWS и считается упавшей после трёх неудач подряд. Это единственный сигнал, который ловит поломку DNS, сертификата или самого балансировщика: внутренние метрики в этот момент выглядят нормально, а сайт недоступен. Её метрики публикуются только в `us-east-1`, поэтому у окружения два SNS-топика — аларм не может публиковать в топик чужого региона.
